# data/creators

방송인 **화이트리스트**.

Phase 1 시드: `whitelist.json` (울프, 김민교, 운타라, Caedrel). UI 목업용입니다.

수집 프로토타입 화이트리스트는 시드와 다릅니다. **LEC · 국내 · 치지직/숲**만:

- 치지직: 와디드, 울프, 강퀴 (울프·강퀴는 거의 중계하지 않음)
- 숲: 롱다리코치, 훈수킹, 아뚱 (아뚱은 거의 중계하지 않음)

김민교·운타라·Caedrel은 LCK/LPL·YouTube 목업용으로 두고, 프로토타입 크롤 대상이 아닙니다.
수집 파이프라인은 아직 이 목록을 크롤하지 않습니다.
