## 제품 방향 (문서만, 미구현)

메인: **위 = 지금 생중계**, **아래 = 다시보기**. 리그: **LCK · LPL · LEC**.

- 상단 vs 카드만. 자동 전환 **LCK → LPL → LEC**, **5초**, 호버 시 정지, 탭으로 직접 선택. 라이브 없는 리그는 건너뜀
- vs 카드를 누른 **경기 화면**에서 스트리머·BJ + 응원 팀 / 플랫폼 필터
- 공식 중계 영상을 임베드하지 않음. 화이트리스트 방송인 라이브로 연결
