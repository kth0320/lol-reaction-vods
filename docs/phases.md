## Phase 1 (현재)

- Next.js + Prisma(SQLite) 로컬 앱
- 메인 **위**: LCK · LPL · LEC 생중계 vs 카드. **5초** 전환, 호버 정지, 탭 선택. 라이브 없는 리그는 건너뜀
- vs 카드를 누른 경기 화면: 지금 중계 중인 방송인 + 응원 팀 / 플랫폼 필터
- 메인 **아래**: 지난 경기 다시보기. YouTube·숲 iframe, 치지직 링크 아웃
- `data/` JSON 시드 (라이브는 플레이스홀더 vs 카드)
- 수집 워커·관리 화면·공식 vs 에셋 파이프라인 **없음**

Phase 1 UI는 세 리그 탭·캐러셀을 그대로 둡니다. 라이브 없는 리그는 건너뜁니다. 수집이 붙기 전에는 시드가 LCK/LPL을 채울 수 있고, 프로토타입 수집이 붙으면 실제 후보는 **LEC만** 나옵니다.

## Phase 2 — 수집 프로토타입 (다음)

LCK 중계진을 처음부터 넣지 않습니다. 채널이 많아서 매칭·운영이 프로토타입보다 먼저 커집니다.

- 리그: **LEC만**. LCK · LPL은 프로토타입이 돈 뒤에 추가
- 플랫폼: **치지직 · 숲 · Twitch 라이브**(원본 링크). YouTube 수집과 Twitch 다시보기는 이후
- 방송인:
  - 국내: 치지직 와디드·울프·강퀴, 숲 롱다리코치·훈수킹·아뚱 (울프·강퀴·아뚱은 거의 안 켜도 목록에 둠)
  - 해외 Twitch: Caedrel(풀 슬레이트), Jankos(G2), YamatoCannon(SK), Kameto(KC), Ibai(KOI 위주), Obsess(FNC 위주)
- 파이프라인: 화이트리스트 채널 ID + 경기 시간창 → `LiveCandidate` 후보. 홈 `LiveCast`에 자동 게시하지 않음
- 채널 ID는 `data/creators/channels.json`에 저장. 검색으로 매번 다시 찾지 않음
- LCK/LPL 시드 중계진(김민교·운타라 등)은 이 페이즈에서 크롤하지 않음

성공: LEC 한 경기에서 국내 또는 해외 화이트리스트 라이브가 **시드가 아닌 수집 결과**로 붙는다. 확인 화면: `/candidates`. 홈 `LiveCast`에는 아직 자동 게시하지 않음.
