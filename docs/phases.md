## Phase 1 (현재)

- Next.js + Prisma(SQLite) 로컬 앱
- 메인 **위**: 프로토타입은 **LCK · LEC** 생중계 vs 카드. **5초** 전환, 호버 정지, 탭 선택. 라이브 없는 리그는 건너뜀. LPL은 이 페이즈에서 비활성
- vs 카드를 누른 경기 화면: 지금 중계 중인 방송인(프로필·플랫폼·응원 팀·시청자 수) + 응원 팀 / 플랫폼 필터
- 메인 **아래**: 지난 경기 다시보기. YouTube·숲 iframe, 치지직 링크 아웃
- `data/` JSON 시드 (라이브는 플레이스홀더 vs 카드)
- 수집 워커·관리 화면·공식 vs 에셋 파이프라인 **없음**

Phase 1 UI의 홈 vs 카드는 시드 대신, 화이트리스트 제목에서 읽은 **LCK·LEC** 경기를 씁니다.

## Phase 2 — 수집 프로토타입 (다음)

- 화이트리스트: 대회 중계를 자주 하는 채널만 **수동** 등록. LCK 국내 + LEC 해외 Twitch. 그 사람들이 **지금 켠 리그** 제목으로 경기를 읽는다
- 홈에서 켜는 리그: **LCK · LEC**. LPL 제목은 카드를 만들지 않음
- 플랫폼: **치지직 · 숲 · Twitch 라이브**(원본 링크). YouTube 수집과 Twitch 다시보기는 이후
- 홈 vs 카드: 제목에서 리그·두 팀. 시드 젠지 vs DK는 쓰지 않음
- 파이프라인: 채널 ID 조회 → `LiveCandidate` → 제목 추론 경기는 홈에 표시
- **나중에:** 공식 일정 API로 vs 카드 갱신. 제목 추론은 보조로 남긴다

성공: 화이트리스트가 켠 LCK 또는 LEC 경기가 시드가 아니라 수집 결과로 홈 카드와 경기 화면에 붙는다.
