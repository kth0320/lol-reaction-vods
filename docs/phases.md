## Phase 1

- Next.js + Prisma(SQLite) 로컬 앱
- 메인 **위**: 프로토타입은 **LCK · LEC** 생중계 vs 카드. **5초** 전환, 호버 정지, 탭 선택. 라이브 없는 리그는 건너뜀. LPL은 이 페이즈에서 비활성
- vs 카드를 누른 경기 화면: 지금 중계 중인 방송인(프로필·플랫폼 로고·시청자 수) + 플랫폼 필터
- 메인 **아래**: 지난 경기 다시보기. 유튜브·숲·치지직 원본으로 이동
- `data/` JSON 시드 (라이브는 플레이스홀더 vs 카드)
- 수집 워커·관리 화면·공식 vs 에셋 파이프라인 **없음**

Phase 1 UI의 홈 vs 카드는 시드 대신 **LCK·LEC 공식 일정**입니다. 방송 제목은 그 경기에 중계진을 붙일 때만 씁니다.

## Phase 2 — 수집 프로토타입

- 화이트리스트: 대회 중계를 자주 하는 채널만 **수동** 등록. LCK 국내 + LEC 해외 Twitch
- 홈에서 켜는 리그: **LCK · LEC**. LPL은 카드를 만들지 않음
- 플랫폼: **치지직 · 숲 · Twitch 라이브**(원본 링크). Twitch 원본 VOD는 가져오지 않음
- **홈 vs 카드: lolesports 공식 일정.** `inProgress`와 시작 90분 전~시리즈 예상 시간 안의 `unstarted`. `getSchedule`이 `completed`여도 스코어가 시리즈를 끝내지 않았거나 `getEventDetails` 게임이 `inProgress`면 라이브. TBD 슬롯은 건너뜀. 리그 ID는 slug로 조회하고 하드코딩하지 않음
- 제목 추론은 **보조**. 화이트리스트 라이브 제목의 리그·두 팀을 공식 경기에 매칭해 `LiveCandidate.matchId`만 붙인다. ingest 경기를 만들어 홈에 올리지 않음
- 파이프라인: `getLeagues` → `getSchedule` → `Match(source=schedule)` → 채널 조회 → `LiveCandidate`

성공: 공식 LCK 또는 LEC 경기가 시드·방송 제목이 아니라 일정 API로 홈 카드가 된다. 중계 중인 화이트리스트는 그 경기 화면에 붙는다.

## Phase 3 — 다시보기 대회 허브

홈 아래를 시드 목록 대신 **대회 카드 7장**으로 나눈다. 카드를 누르면 그 대회의 스트리머·BJ 다시보기만 보인다. 팀 약자·이름 검색은 **7장 모두 같은 화면**(`/vods/[tournament]`)이다. 롤드컵·MSI·퍼스트스탠드·EWC·LPL 목록을 나중에 채워도 검색을 허브마다 새로 만들지 않는다.

```
롤드컵   MSI   퍼스트스탠드   EWC
LCK     LPL   LEC
```

## Phase 4 — 다시보기 수집 (현재)

화이트리스트 채널에서 끝난 대회 경기에 리액션 VOD를 붙인다.

- YouTube: 채널 RSS + uploads/동영상 탭 페이징(상대 날짜). Twitch로 생중계하는 방송인도 YouTube만
- 치지직·숲: 방송국 다시보기
- Twitch 원본 VOD는 가져오지 않음
- 제목의 대회·두 팀 + 경기 시간창으로 **끝난** 공식 경기에만 붙임. 생중계 중 다시보기는 진행 중 방송이라 캐스터 보드만 쓴다. ingest 경기를 만들지 않음. 같은 경기·같은 방송인·같은 플랫폼은 다시보기 하나(대기방·재연결보다 본 방송)
- 라이브 제목은 바뀔 때마다 저장하고, **다시보기·하이라이트처럼 제목이 비었을 때만** 같은 플랫폼·같은 방송 세션의 라이브 제목·경기 id로 붙인다. FC온라인 같은 다른 방송에는 안 붙인다. 다음 날 다른 방송 제목은 어제 VOD에 안 붙인다
- 치지직 검색·Twitch GQL 검색으로 지금 공식 경기를 중계하는 채널을 화이트리스트 없이 넣는다. JSON 채널은 그대로고, 자동 수집 채널은 sync 때 지우지 않는다. 숲 검색 API는 공개 엔드포인트가 없어 화이트리스트만
- 일정 API는 LCK·LEC뿐 아니라 **LPL · 롤드컵 · MSI · 퍼스트스탠드 · EWC** 끝난 경기도 저장한다. 홈 상단 라이브 탭은 **LCK · LPL · LEC**
- 대회 화면 팀 검색은 약자 단어 단위다. `KT`가 T1의 옛 별칭 `SKT`에 부분 일치하지 않는다
- LCK·LPL·LEC는 **시즌 + 스플릿** 셀렉트(LCK컵/LCK, Split 1–3/선발전, 버서스/스프링/서머). 국제전은 **연도 + 구간**. 필터는 URL(`?year=&stage=&q=`)에 남고, 끝난 경기에서 같은 허브로 돌아온다. 홈 대회 카드는 `경기 N · 리액션 M`
- 지난 시즌 아카이브: `getTournamentsForLeague` + `getCompletedEvents`로 2026·2025·2024 끝난 경기를 저장한다. 치지직·숲은 방송국 페이지를 더 넘긴다(최대 50). 숲은 한 페이지가 실패해도 다음 페이지를 이어 가져온다. YouTube는 RSS 이후 InnerTube 페이지를 더 넘긴다. 홈 라이브 동기화는 최근 `getSchedule` 페이지만
- 보정: `/ops`에서 자동 매칭을 보고 끊거나 YouTube·치지직·숲 주소를 붙인다. 조회는 TypeScript DTO + `/api/ops/*`. `OPS_PASSWORD`가 있으면 쿠키 로그인
- 홈·라이브 경기 vs 카드는 **공식 매치업 플레이트**(리그 마크 + 양 팀 로고). `getLeagues`·`getEventDetails` 이미지를 https로 쓰고, 마크·로고가 없을 때만 공식 중계 음소거. 합성된 T1-vs-KT JPG는 API에 없다
- 생방송·다시보기는 누렁카세 안에서 재생하지 않는다. 치지직·숲·유튜브·Twitch 원본 영상으로 보낸다. 치지직 다시보기가 먼저 붙고, 유튜브 영상이 생기면 유튜브 영상 링크를 추가한다. Twitch 원본 VOD는 모으지 않음
- 홈 대회 카드는 공식 리그 마크를 가운데에 흐리게 깔고, 생중계가 없는 리그는 같은 vs 카드에 다음 경기(예정)를 보여 준다. 클릭하지 않는다. 다음 일정이 없으면 `다음 일정이 없습니다`
