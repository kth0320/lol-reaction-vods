## Phase 1 (현재)

- Next.js + Prisma(SQLite) 로컬 앱
- 메인 **위**: LCK · LPL · LEC 생중계 vs 카드. **5초** 전환, 호버 정지, 탭 선택. 라이브 없는 리그는 건너뜀
- vs 카드를 누른 경기 화면: 지금 중계 중인 방송인 + 응원 팀 / 플랫폼 필터
- 메인 **아래**: 지난 경기 다시보기. YouTube·숲 iframe, 치지직 링크 아웃
- `data/` JSON 시드 (라이브는 플레이스홀더 vs 카드)
- 수집 워커·관리 화면·공식 vs 에셋 파이프라인 **없음**

Phase 1 UI는 세 리그 탭·캐러셀을 그대로 둡니다. 라이브 없는 리그는 건너뜁니다. 홈 vs 카드는 시드 대신, 화이트리스트 제목에서 읽은 경기를 씁니다.

## Phase 2 — 수집 프로토타입 (다음)

LCK 중계진 전체를 처음부터 넣지 않습니다. 채널이 많아서 매칭·운영이 프로토타입보다 먼저 커집니다.

- 화이트리스트: LEC 국내 + 해외 Twitch 6명. 그 사람들이 **지금 켠 리그**(오늘 LCK여도) 제목으로 경기를 읽는다
- 플랫폼: **치지직 · 숲 · Twitch 라이브**(원본 링크). YouTube 수집과 Twitch 다시보기는 이후
- 홈 vs 카드: 제목에서 리그·두 팀. 시드 젠지 vs DK는 쓰지 않음
- 파이프라인: 채널 ID 조회 → `LiveCandidate` → 제목 추론 경기는 홈에 표시
- **나중에:** 공식 일정 API로 vs 카드 갱신. 제목 추론은 보조로 남긴다
- LCK/LPL 시드 중계진(김민교·운타라 등)은 이 페이즈에서 크롤하지 않음

성공: 화이트리스트가 켠 경기(예: LCK KT vs BRO)가 시드가 아니라 수집 결과로 홈 카드와 경기 화면에 붙는다.
