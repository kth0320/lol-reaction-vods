# LoL 리액션 VOD

롤 대회 **공식 중계 플레이어**가 아닙니다.  
지금 열리는 경기를 **같이 중계하는 스트리머·BJ**에게 연결하고, 끝난 경기는 **다시보기**로 모아 주는 사이트입니다.

생방송일 때: 「이 경기 지금 누가 중계하지?」  
끝난 뒤: 「이 경기 리액션 누가 했지?」

> 사이트 브랜드 후보: 누렁카세 / 누렁이 특식 (미정). 레포명: `lol-reaction-vods`. 음식·레스토랑 서비스가 아닙니다.

## 무엇을 하나요

메인 화면은 위가 라이브, 아래가 다시보기입니다.

대상 리그는 **LCK · LPL · LEC** 세 개입니다. (다른 리그는 후순위)

수집 **프로토타입**은 그 세 리그를 한 번에 하지 않습니다. LCK는 국내 중계가 많아서 화이트리스트·매칭이 바로 무거워집니다. 프로토타입이 라이브 허브로 한 바퀴 돌 때까지는 **LEC만**. 국내는 **치지직 · 숲**, 해외는 **Twitch 라이브**(원본 링크). LCK · LPL · YouTube 수집 · Twitch 다시보기는 그 다음에 붙입니다.

### 위: 지금 생중계

- 경기가 진행 중이면 상단에 **크게** 띄웁니다. 예: Gen.G vs Dplus KIA 생방송 중.
- 카드는 **리그 공식 vs 이미지**(해당 리그 매치 그래픽)를 우선 사용합니다. 공식 중계 영상 자체를 가져와 틀지 않습니다.
- 라이브가 있는 리그만 돌립니다. 순서: **LCK → LPL → LEC → LCK**. 안 하는 리그는 건너뜁니다.
- **5초**마다 다음 리그로 바뀝니다. 카드 위에 마우스를 올리면 멈춥니다.
- **LCK / LPL / LEC 탭**으로 기다리지 않고 해당 리그를 고를 수 있습니다.
- 메인 상단에는 vs 카드만 둡니다. 응원 팀·플랫폼 필터와 스트리머 목록은 여기에 깔지 않습니다.
- vs 카드를 누르면 **그 경기 화면**으로 들어갑니다. 거기서 지금 중계 중인 스트리머·BJ가 나오고, 다음 두 가지로 나눕니다.
  - **응원 팀** — 블루 / 레드(또는 특정 팀) / 중립
  - **플랫폼** — YouTube · 숲(SOOP) · 치지직 · Twitch
- 세 리그 모두 생방송이 없으면 이 블록은 접히거나 비어 있고, 다시보기만 보입니다.

### 아래: 다시보기

- 대회 일정 / 지난 경기 목록에서 경기를 고릅니다.
- 그 경기를 중계·리액션한 방송인과 플랫폼별 다시보기로 이동합니다.
- **YouTube · 숲(SOOP)** 다시보기는 사이트 안에서 공식 임베드(iframe/퍼가기)로 재생합니다.
- **치지직** 다시보기·라이브는 원본 링크로 연결합니다. (인페이지 임베드는 후순위)

영상을 다운로드하거나 우리 서버에 호스팅하지 않습니다. 플랫폼 플레이어·공식 링크만 사용합니다.  
라이브도 같습니다. 리그 공식 스트림이 아니라 화이트리스트 방송인의 생방송으로 보냅니다.

## 다시보기·라이브는 어떻게 모으나요

플랫폼에 「이 경기만 주세요」 API는 없습니다. 대신 아래를 함께 씁니다.

1. **방송인 화이트리스트** — 리액션·중계를 자주 하는 채널만 등록
2. **경기 시간창** — 경기 전후에 라이브 중이거나 생성된 VOD를 후보로 수집
3. **제목 점수** — `T1` / `티원`, `Gen.G` / `GEN` / `젠지` 같은 팀 별칭으로 보조 매칭
4. **응원 팀** — 방송인이 어느 팀을 보고 있는지(또는 중립). 라이브 목록 필터에 사용
5. **수동 보정** — 자동 매칭이 놓치거나 틀린 링크는 관리 화면에서 연결·해제

Phase 1은 시드 JSON으로 라이브 허브(다시보기 포함)를 보여 줍니다. 수집 워커와 관리 화면은 아직 없습니다.

다음 수집(프로토타입) 범위는 아래와 같습니다.

| 항목 | 프로토타입 | 이후 |
| --- | --- | --- |
| 리그 | **LEC만** | LCK, LPL |
| 플랫폼 | **치지직 · 숲 · Twitch 라이브** | YouTube, Twitch 다시보기 |
| 방송인 | LEC 국내 + 아래 해외 6명 | LCK/LPL 중계진, 그 외 채널 |
| 공개 | 후보 수집. 홈에 자동 올리지 않음 | 운영 화면에서 확인 후 게시 |

프로토타입 화이트리스트 (안 켜는 날이면 후보 0이 정상입니다). 채널 ID는 `data/creators/channels.json`에 수동으로 넣는다.

- 치지직: **와디드**, 울프, 강퀴 (울프·강퀴는 거의 중계하지 않음)
- 숲: **롱다리코치**, **훈수킹**, 아뚱 (아뚱은 거의 중계하지 않음)
- Twitch: **Caedrel**(풀 슬레이트), **Jankos**(G2), **YamatoCannon**(SK), **Kameto**(KC), **Ibai**(KOI 경기 위주), **Obsess**(FNC 위주)

2026 LEC 공식 팀 코스트리머는 자기 팀 기본 응원으로 둔다. Ibai는 KOI, Obsess는 FNC. Caedrel은 자기 팀(Los Ratones)이 있어도 리그 전체를 중계하므로 기본 응원을 비운다.

성공 기준: LEC 경기 시간창에 와디드·롱다리코치·훈수킹·Caedrel·Jankos 중 한 명이 켜면, 시드가 아니라 수집 후보로 그 경기가 잡힌다. Twitch는 라이브 링크만. VOD는 휘발되어서 프로토타입에서 모으지 않는다.

## 지원 플랫폼

| YouTube | 프로토타입 이후 | 공식 embed iframe | 공식 라이브 embed 또는 원본 |

## 로컬 실행

지금 로컬 앱은 상단 생중계 캐러셀(LCK · LPL · LEC, 5초)과 하단 다시보기입니다. 공식 vs 이미지는 플레이스홀더 카드입니다.

```bash
npm install
npx prisma migrate dev
npx prisma db seed
npm run dev -- -p 43123
```

브라우저에서 `http://localhost:43123` → 상단 vs 카드(리그 탭 / 5초 전환) → 경기 화면(응원 팀·플랫폼 필터) / 하단 다시보기.

시드 데이터는 `data/` JSON입니다. SQLite 파일(`prisma/dev.db`)은 커밋하지 않습니다.

## 레포 구조

Phase 1 공개 사이트는 레포 루트 Next.js 앱입니다 (`app/`, `lib/`, `prisma/`).

| 경로 | 역할 |
| --- | --- |
| `app/` | 메인(생중계 캐러셀 + 다시보기), 경기별 라이브/리액션 페이지 |
| `lib/playback.ts` | YouTube·숲 임베드 / 치지직·Twitch 링크 아웃 |
| `prisma/` | 스키마·마이그레이션·시드 |
| `data/creators/` | 방송인 화이트리스트·채널 ID JSON |
| `lib/creators.ts` | 프로토타입 수집 대상 필터 |
| `data/team-aliases/` | 제목 점수용 팀 별칭 (팀 시드는 `data/teams.json`) |
| `data/matches/` | 경기/일정 JSON |
| `data/reactions/` | Phase 1 시드 다시보기 링크 |
| `data/live-casts/` | Phase 1 시드 라이브 중계 링크 |
| `data/corrections/` | 이후 수동 보정 |
| `apps/web/`, `apps/ops/` | 이후 분리용 placeholder |
| `services/ingest/` | 수집 파이프라인 (아직 없음) |
