# lol-reaction-vods

롤(LoL) 대회 **리액션 다시보기 아그리게이터**.

경기/일정 기준으로 「이 경기 리액션 누가 했지?」를 보여 주는 사이트다.  
공식 대회 VOD 아카이브가 아니며, 음식·레스토랑·메뉴 서비스도 아니다.

GitHub 레포명 `lol-reaction-vods`는 고정이다. 사이트 브랜드(표시명)는 아직 미정이다.

## 브랜드 (미정)

UI 카피용 후보일 뿐, 제품 도메인과 무관하다.

| 후보 | 상태 |
| --- | --- |
| 누렁카세 | 미정 |
| 누렁이 특식 | 미정 |

「특식」은 브랜드 말장난이다. 음식 배달, 식당, 메뉴판으로 해석하지 않는다.

## 제품

### 한 줄

**이 경기를 누가 리액션했는지**를 모아 보여 준다.

### 대상 콘텐츠

- 대상: 스트리머 · BJ · 유튜버 · 버튜버의 **다시보기(VOD)**
- 비대상: 공식 대회 중계/하이라이트 VOD, 리그 공식 채널 아카이브

### 사용자 질문

1. 오늘/이번 주 경기 목록은?
2. 이 경기를 리액션한 방송인은 누구인가?
3. 그 다시보기를 어디서 볼 수 있는가? (재생 또는 원본 링크)

### 플랫폼

| 플랫폼 | 수집 | 재생 |
| --- | --- | --- |
| YouTube | 예 | 공식 iframe 임베드 |
| 숲 (SOOP) | 예 | 공식 iframe 임베드 |
| 치지직 (Chzzk) | 예 | **링크 아웃만** (iframe 없음) |

치지직은 공식 임베드 경로가 없으므로 사이트 안에서 재생하지 않고 원본으로 보낸다.

### 수집

자동 매칭 후 사람이 고친다.

1. **방송인 화이트리스트** — 수집 대상 크리에이터만
2. **경기 시간창** — 해당 경기 전후 방송 구간만 후보
3. **제목 매칭** — 팀명·팀 별칭이 제목에 있는지
4. **수동 보정** — 오매칭 제거, 누락 추가, 경기 연결 수정

## 범위 밖 (Phase 0 포함 이후에도 기본 비목표)

- 공식 대회 VOD 플레이어/아카이브
- 음식, 레스토랑, 레시피, 메뉴, 배달
- 치지직 iframe 재생
- UI · 비즈니스 로직 · API · 페이지 구현 (**Phase 0에서 금지**)

## Phase 0

지금 레포에 있는 것:

- 이 README
- 이후 단계가 붙을 **폴더/placeholder** (`*/README.md`)
- 루트 `.gitignore`

지금 레포에 없는 것:

스택·프레임워크는 이후 페이즈에서 정한다.

## 폴더

| 경로 | 역할 |
| --- | --- |
| `apps/web/` | 공개 사이트 (경기 목록, 경기별 리액션, YouTube·숲 임베드 / 치지직 아웃링크) |
| `apps/ops/` | 수동 보정용 운영 도구 |
| `services/api/` | 경기·리액션 조회 API |
| `services/ingest/` | 화이트리스트 + 시간창 + 제목 매칭 수집 |
| `packages/shared/` | 공유 도메인 설명 (플랫폼, 재생 정책, 매칭 개념) |
| `data/creators/` | 방송인 화이트리스트 |
| `data/team-aliases/` | 제목 매칭용 팀 별칭 |
| `data/matches/` | 경기/일정 식별 데이터 |
| `data/corrections/` | 수동 보정(오버라이드) |
| `docs/` | 페이즈·제품 메모 |

각 폴더는 placeholder README만 둔다. 구현 파일은 이후 페이즈에서 추가한다.

## 이후 페이즈 (구현하지 않음)

대략적인 순서일 뿐, 이 PR에서 코드로 시작하지 않는다.

1. 도메인 모델 — 경기, 방송인, 플랫폼, 리액션 VOD, 매칭 결과
2. 시드 데이터 — 화이트리스트, 팀 별칭, 경기 일정
3. 수집 — 시간창 + 제목 매칭, 수동 보정 입력
4. 조회 — 경기 기준으로 리액션 목록
5. 공개 UI — 일정/경기 선택 → 리액션 목록 → YouTube·숲 임베드, 치지직 링크 아웃

## 라이선스 / 콘텐츠

다시보기 원본은 각 플랫폼·방송인에게 있다. 이 사이트는 메타데이터와 공식 임베드/아웃링크만 다룬다. 공식 중계 재배포가 목적이 아니다.
