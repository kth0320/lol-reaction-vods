# LoL 리액션 VOD

롤 대회 **공식 중계 플레이어**가 아닙니다.  
지금 열리는 경기를 **같이 중계하는 스트리머·BJ**에게 연결하고, 끝난 경기는 **다시보기**로 모아 주는 사이트입니다.

생방송일 때: 「이 경기 지금 누가 중계하지?」  
끝난 뒤: 「이 경기 리액션 누가 했지?」

> 사이트 브랜드 후보: 누렁카세 / 누렁이 특식 (미정). 레포명: `lol-reaction-vods`. 음식·레스토랑 서비스가 아닙니다.

## 무엇을 하나요

메인 화면은 위가 라이브, 아래가 다시보기입니다.

대상 리그는 **LCK · LPL · LEC** 세 개입니다. (다른 리그는 후순위)

수집 **프로토타입**은 **LCK와 LEC만** 켭니다. LPL은 탭·홈 카드에서 빼 둡니다. 지금은 대회 중계를 자주 하는 채널만 **수동 화이트리스트**로 넣습니다. 국내는 **치지직 · 숲**, 해외 LEC는 **Twitch 라이브**(원본 링크). 다시보기는 YouTube와 치지직·숲 방송국 VOD입니다. Twitch 원본 다시보기는 가져오지 않습니다.

### 위: 지금 생중계

- 경기가 진행 중이면 상단에 **크게** 띄웁니다. 예: Gen.G vs Dplus KIA 생방송 중.
- **vs 카드는 LCK·LEC 공식 일정**(lolesports 스케줄)입니다. 방송 제목으로 경기를 만들지 않습니다.
- 카드는 **공식 매치업 플레이트**(리그 마크 + 양 팀 공식 로고)를 우선 사용합니다. lolesports에 합성 vs JPG는 없어서 마크와 로고로 판을 만듭니다. 마크·로고가 없을 때만 **공식 중계 음소거 프리뷰**를 씁니다. 카드를 눌러 공식 플레이어로 시청하는 화면이 아닙니다.
- 라이브가 있는 리그만 돌립니다. 순서: **LCK → LEC → LCK**. LPL은 프로토타입에서 건너뜁니다.
- **5초**마다 다음 리그로 바뀝니다. 카드 위에 마우스를 올리면 멈춥니다.
- **LCK / LEC 탭**으로 기다리지 않고 해당 리그를 고를 수 있습니다.
- 메인 상단에는 vs 카드만 둡니다. 응원 팀·플랫폼 필터와 스트리머 목록은 여기에 깔지 않습니다.
- vs 카드를 누르면 **그 경기 화면**으로 들어갑니다. 지금 중계 중인 스트리머·BJ는 프로필 사진, 방송 플랫폼, 응원 팀, 시청자 수 행으로 나옵니다. 필터는 다음 두 가지입니다.
  - **응원 팀** — 블루 / 레드(또는 특정 팀) / 중립
  - **플랫폼** — YouTube · 숲(SOOP) · 치지직 · Twitch
- LCK · LEC 모두 생방송이 없으면 이 블록은 접히거나 비어 있고, 다시보기만 보입니다.

### 아래: 다시보기

- 홈 아래는 대회 카드 7장입니다. `롤드컵 · MSI · 퍼스트스탠드 · EWC` / `LCK · LPL · LEC`.
- 카드를 누르면 그 대회 스트리머·BJ 다시보기만 보입니다. LCK·LEC·LPL·국제전은 공식 일정의 끝난 경기에 리액션이 붙으면 목록에 쌓입니다. 홈 카드에는 `경기 N · 리액션 M`이 보입니다.
- 팀 검색은 7개 대회 화면이 같은 칸입니다. 약자·이름·별칭만 보고, `KT`가 `SKT`(T1 옛 이름) 같은 다른 팀 문자열에 부분 일치하지 않습니다.
- **LCK · LPL · LEC** 화면은 시즌 셀렉트 옆에 스플릿이 있습니다. LCK는 `LCK컵 / LCK`, LPL은 `Split 1 / 2 / 3 / 선발전`, LEC는 `버서스 / 스프링 / 서머`입니다. **롤드컵 · MSI · 퍼스트스탠드 · EWC**는 연도 옆에 구간(스위스·녹아웃 등)이 있습니다. 연도·스플릿·검색은 주소에 남아서 공유할 수 있고, 끝난 경기에서 뒤로 가면 그 필터로 돌아갑니다. 2025·2024 칸은 `ingest:schedule`과 `ingest:vods`를 돌리면 채워집니다. YouTube RSS에 없는 지난 해 영상은 치지직·숲 방송국에서 가져옵니다.
- 그 경기를 중계·리액션한 방송인과 플랫폼별 다시보기로 이동합니다.
- **YouTube · 숲(SOOP)** 다시보기는 사이트 안에서 공식 임베드(iframe/퍼가기)로 재생합니다.
- **치지직** 다시보기·라이브는 원본 링크로 연결합니다. (인페이지 임베드는 후순위)
- Twitch로 생중계하는 방송인의 다시보기는 **유튜브에 올린 영상만** 가져옵니다. Twitch 원본 VOD는 휘발되어서 모으지 않습니다. 치지직·숲 방송인은 방송국 다시보기와 유튜브 편집본을 같이 둡니다.

영상을 다운로드하거나 우리 서버에 호스팅하지 않습니다. 플랫폼 플레이어·공식 링크만 사용합니다.  
라이브도 같습니다. 리그 공식 스트림이 아니라 화이트리스트 방송인의 생방송으로 보냅니다.

## 다시보기·라이브는 어떻게 모으나요

플랫폼에 「이 경기만 주세요」 API는 없습니다. 대신 아래를 함께 씁니다.

1. **방송인 화이트리스트** — 리액션·중계를 자주 하는 채널만 등록
2. **경기 시간창** — 경기 전후에 라이브 중이거나 생성된 VOD를 후보로 수집
3. **제목 점수** — `T1` / `티원`, `Gen.G` / `GEN` / `젠지` 같은 팀 별칭으로 **공식 경기에 방송인을 붙이는** 보조 매칭
4. **응원 팀** — 방송인이 어느 팀을 보고 있는지(또는 중립). 라이브 목록 필터에 사용
5. **수동 보정** — 자동 매칭이 놓치거나 틀린 링크는 관리 화면에서 연결·해제

Phase 1은 시드 JSON으로 라이브 허브(다시보기 포함)를 보여 줍니다. 수집 워커와 관리 화면은 아직 없습니다.

다음 수집(프로토타입) 범위는 아래와 같습니다.

| 항목 | 프로토타입 | 이후 |
| --- | --- | --- |
| 리그 | **라이브 홈: LCK · LEC만**. LPL은 홈에 안 올림. 다시보기 허브는 LPL·롤드컵·MSI·퍼스트스탠드·EWC 일정도 저장 | LPL 라이브 활성화 |
| 플랫폼 | **치지직 · 숲 · Twitch 라이브** + YouTube·치지직·숲 다시보기 | Twitch 원본 VOD는 안 함 |
| 방송인 | 대회 중계를 자주 하는 채널만 **수동** 등록 | 자동 수집 API로 가끔 중계하는 채널도 붙임 |
| 홈 vs 카드 | **공식 일정 API**(lolesports). 진행 중·시작 직전 경기. 카드 면은 리그 마크+팀 로고 | 더 많은 리그 |
| 중계진 연결 | 라이브 **제목에서 리그·두 팀**을 읽어 그 공식 경기에 붙임 | 운영 화면에서 확인 후 게시 |
| 공개 | 공식 LCK·LEC 경기는 홈에 올림. 운영 화면 승인은 아직 없음 | 운영 화면 |

홈 상단은 시드(젠지 vs DK)를 쓰지 않는다. 방송 제목으로 ingest 경기를 만들지도 않는다. 메인에 들어오면 공식 일정을 맞춰 두고, 화이트리스트 조회는 뒤에서 돈다. LEC가 꺼져 있으면 LCK만 돌린다.

팀 별칭이 `data/teams.json`에 있어야 제목으로 중계진을 붙일 수 있다. 일정 API 팀 코드(DNS, KRX, MKOI 등)는 별칭·코드 맵으로 우리 팀 id에 맞춘다.

프로토타입 화이트리스트는 **수동**이다. 채널 ID는 `data/creators/channels.json`에 넣는다. 안 켜는 날이면 그 채널은 후보 0이 정상이다. 그래도 공식 경기가 진행 중이면 vs 카드는 나온다.

- 치지직: 운타라, 울프, 강퀴, 탬탬버린, 베릴, 와디드
- 숲: 김민교, 롱다리코치, 훈수킹, 아뚱, 클리드, 이상호, 김군, 안녕수야
- Twitch: **Caedrel**(풀 슬레이트), **Jankos**(G2), **YamatoCannon**(SK), **Kameto**(KC), **Ibai**(KOI 경기 위주), **Obsess**(FNC 위주)

괴물쥐·랄로·앰비션·따효니·풍월량·러너는 롤 대회 중계를 거의 안 해서 지금은 빼 둔다. 나중에 자동으로 켜진 방송을 붙이는 API가 생기면 그때 다시 보이면 된다.

운타라는 T1, 안녕수야는 GEN, 와디드는 G2 기본 응원. 2026 LEC 공식 팀 코스트리머는 자기 팀 기본 응원으로 둔다. Ibai는 KOI, Obsess는 FNC. Caedrel은 자기 팀(Los Ratones)이 있어도 리그 전체를 중계하므로 기본 응원을 비운다.

성공 기준: 공식 LCK·LEC 일정의 진행 중(또는 시작 직전) 경기가 시드·제목 추론이 아니라 홈 vs 카드로 뜬다. 화이트리스트가 그 경기를 중계 중이면 제목으로 그 카드에 붙는다. LPL·국제전 일정은 홈 카드를 만들지 않고 다시보기 대회 허브에만 쌓인다. Twitch는 라이브 링크만. 그 방송인 다시보기는 YouTube만 모은다. Twitch 원본 VOD는 가져오지 않는다.

## 지원 플랫폼

| 플랫폼 | 수집 | 사이트 내 재생 (다시보기) | 라이브 |
| --- | --- | --- | --- |
| 치지직 | 프로토타입 라이브 + 방송국 다시보기 (LCK · LEC · 국내) | 원본 링크만 | 원본 링크만 |
| 숲 (SOOP) | 프로토타입 라이브 + 방송국 다시보기 (LCK · LEC · 국내) | 공식 퍼가기 iframe (+ 원본 링크) | 원본 링크 |
| Twitch | 프로토타입 라이브만 (LEC · 해외 6명) | 안 함. 다시보기는 그 방송인 YouTube | 원본 링크만 |
| YouTube | 프로토타입 다시보기 (화이트리스트 채널 RSS) | 공식 embed iframe | 공식 라이브 embed 또는 원본 |

## 로컬 실행

지금 로컬 앱은 상단 생중계 카드가 **LCK·LEC 공식 일정**이고, 카드 면은 공식 리그 마크와 팀 로고입니다. 하단 다시보기는 대회 카드 7장입니다.

```bash
npm install
npx prisma migrate dev
npx prisma db seed
npm run dev -- -p 43123
```

브라우저에서 `http://localhost:43123` → 상단 vs 카드(LCK / LEC 탭 / 5초 전환) → 경기 화면(응원 팀·플랫폼 필터) / 하단 다시보기.  
수집 후보는 `http://localhost:43123/candidates`. 일정만: `npm run ingest:schedule` (최근 창 + 2026·2025·2024 끝난 대회). 화이트리스트 라이브: `npm run ingest:live`. 다시보기: `npm run ingest:vods` (치지직·숲은 지난 시즌까지 페이지).

시드 데이터는 `data/` JSON입니다. SQLite 파일(`prisma/dev.db`)은 커밋하지 않습니다.

| --- | --- |
| `app/` | 메인(생중계 캐러셀 + 다시보기), 경기별 라이브/리액션 페이지 |
| `lib/playback.ts` | YouTube·숲 임베드 / 치지직·Twitch 링크 아웃 |

| `data/team-aliases/` | 제목 점수용 팀 별칭 (팀 시드는 `data/teams.json`) |

| `data/reactions/` | Phase 1 시드 다시보기 링크 |

| `data/corrections/` | 이후 수동 보정 |
