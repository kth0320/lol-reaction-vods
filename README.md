# LoL 리액션 VOD

롤 대회 **공식 중계**가 아니라, 그 경기를 시청자와 함께 본 **스트리머·BJ·유튜버·버튜버의 다시보기**를
경기 일정 기준으로 모아 주는 사이트입니다.

「이 경기 리액션 누가 했지?」에 바로 답하는 게 목표입니다.

> 사이트 브랜드 후보: 누렁카세 / 누렁이 특식 (미정). 레포명: `lol-reaction-vods`. 음식·레스토랑 서비스가 아닙니다.

## 무엇을 하나요

- 대회 일정 / 경기 목록에서 경기를 고릅니다.
- 그 경기를 중계·리액션한 방송인과 플랫폼별 다시보기로 이동합니다.
- **YouTube · 숲(SOOP)** 다시보기는 사이트 안에서 공식 임베드(iframe/퍼가기)로 재생합니다.
- **치지직** 다시보기는 원본 링크로 연결합니다. (인페이지 임베드는 후순위)

영상을 다운로드하거나 우리 서버에 호스팅하지 않습니다. 플랫폼 플레이어·공식 링크만 사용합니다.

## 다시보기는 어떻게 모으나요

플랫폼에 「이 경기 VOD만 주세요」 API는 없습니다. 대신 아래를 함께 씁니다.

1. **방송인 화이트리스트** — 리액션 중계를 자주 하는 채널만 등록
2. **경기 시간창** — 경기 전후에 라이브였거나 생성된 VOD를 후보로 수집
3. **제목 점수** — `T1` / `티원`, `Gen.G` / `GEN` / `젠지` 같은 팀 별칭으로 보조 매칭
4. **수동 보정** — 자동 매칭이 놓치거나 틀린 링크는 관리 화면에서 연결·해제

Phase 1은 4번을 시드 JSON으로 대신합니다. 수집 워커와 관리 화면은 아직 없습니다.

## 지원 플랫폼

| 플랫폼 | 수집 | 사이트 내 재생 |
| --- | --- | --- |
| YouTube | O | 공식 embed iframe |
| 숲 (SOOP) | O | 공식 퍼가기 iframe (+ 원본 링크) |
| 치지직 | O | 원본 링크만 |
| Twitch | 후순위 (VOD 휘발) | — |

## 로컬 실행

```bash
npm install
npx prisma migrate dev
npx prisma db seed
npm run dev -- -p 43123
```

브라우저에서 `http://localhost:43123` → 경기 목록 → 경기 상세(리액션).

시드 데이터는 `data/` JSON입니다. SQLite 파일(`prisma/dev.db`)은 커밋하지 않습니다.

## 레포 구조

Phase 1 공개 사이트는 레포 루트 Next.js 앱입니다 (`app/`, `lib/`, `prisma/`).

| 경로 | 역할 |
| --- | --- |
| `app/` | 경기 목록, 경기별 리액션 페이지 |
| `lib/playback.ts` | YouTube·숲 임베드 / 치지직 링크 아웃 |
| `prisma/` | 스키마·마이그레이션·시드 |
| `data/creators/` | 방송인 화이트리스트 JSON |
| `data/team-aliases/` | 제목 점수용 팀 별칭 (팀 시드는 `data/teams.json`) |
| `data/matches/` | 경기/일정 JSON |
| `data/reactions/` | Phase 1 시드 링크 (이후 수동 보정과 분리) |
| `data/corrections/` | 이후 수동 보정 |
| `apps/web/`, `apps/ops/` | 이후 분리용 placeholder |
| `services/ingest/` | 수집 파이프라인 (아직 없음) |
